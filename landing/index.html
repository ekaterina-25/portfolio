Problems I solve

The common thread is practical data quality: making fragmented product and master data easier to trust, migrate, report and automate.

  • Duplicate and near-duplicate item records in spare part and product catalogues
  • Inconsistent naming, mixed standards, abbreviations and unclear legacy item descriptions
  • Manual Excel-based checking before ERP migration or data enrichment work
  • Data that is not ready for reporting, automation, search or AI-assisted workflows
  • Business rules that exist in people's heads but are not yet formalised as scalable logic
  • AI use cases where confidence, source checking and human review matter more than flashy output

Python · ML

Duplicate Detection in Spare Parts Catalogues

Finds possible duplicate items from messy spare part data using text similarity and domain-aware comparison rules. Handles naming variation, abbreviations and formatting differences while avoiding obvious false matches.

Business value: reduces manual review effort and helps prevent duplicate item creation before catalogue clean-up or ERP migration.
Tools: Python, scikit-learn, pandas, Streamlit

Python · Validation

Item Master Data Validation

Checks item master data against naming rules and ERP constraints before migration or data entry. Flags field-length issues, forbidden characters, casing problems and cross-field inconsistencies.

Business value: catches quality issues early and makes correction work more structured, traceable and repeatable.

Copilot Studio · AI

Product Classifier — Copilot Studio Agent

A Copilot Studio agent that classifies vague item creation requests into the correct internal product group. Uses web search and confidence scoring instead of guessing from the request text alone.

Business value: supports more consistent item creation and reduces classification uncertainty in early request handling.
Tools: Microsoft Copilot Studio, Bing Search · Simulation: Streamlit, Claude AI

Copilot Studio · Workflow

Fastener Normalizer — Copilot Studio Agent

A workflow for harmonising legacy fastener item data in Excel. Normalises standards, size formats and descriptions, then writes corrected output back through an automated Power Automate flow.

Business value: speeds up repetitive standardisation work and shows how AI can support controlled Excel-based data processes.
